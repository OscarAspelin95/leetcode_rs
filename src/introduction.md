# Introduction
Welcome to `LeetCode With Rust`!

This repository is meant for myself to learn more about Data Structures and Algorithms (DSA) using Rust. I realized that using an mdbook for structuring the solutions also enabled me to very easily write explanations to make sure I understand the solutions. In the process, I also realized that other people might benefit from this, hence the public repository.

As a background in bioinformatics with no formal computer science degree, I felt like I was missing a lot of the fundamentals of computer science. In addition, I had mostly worked with Python before and thought it'd be interesting to learn a more low level language.

The book is structured according to Leetcode topics such as arrays, strings, etc. I have tried to put the problems in numerical order for each topic.
